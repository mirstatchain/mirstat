# Mirstat (MIR)

> **Mirstat (MIR)** is a decentralized, post-quantum-ready peer-to-peer electronic cash system designed for the next generation of digital payments. Combining CPU and GPU mining through independent Proof-of-Work algorithms, Mirstat provides a fair, secure, and decentralized network built for long-term sustainability.

---

# Vision

Mirstat was created with a simple goal:

> Build a cryptocurrency that remains decentralized, accessible, and resilient in the era of quantum computing.

As computational technologies evolve, blockchain infrastructure must adapt. Mirstat embraces modern cryptography, distributed consensus, and balanced mining participation to create a network that can continue operating securely for decades.

The protocol is designed around fairness, predictable monetary issuance, and equal opportunities for miners using both commodity CPUs and GPUs.

# Consensus

Mirstat utilizes a **dual Proof-of-Work architecture**, allowing both CPUs and GPUs to contribute to network security.

## CPU Algorithm

**RandomX**

RandomX is optimized for general-purpose processors and is designed to discourage specialized mining hardware while maintaining high security.

Advantages:

- ASIC resistant
- Fair CPU mining
- Widely tested
- Strong decentralization

---

## GPU Algorithm

**BLAKE3**

BLAKE3 provides extremely high throughput for graphics processors while maintaining excellent cryptographic properties and modern performance characteristics.

Advantages:

- High performance
- Efficient GPU utilization
- Fast verification
- Low computational overhead

# Why Dual Mining?

Traditional Proof-of-Work networks often become dominated by a single hardware class.

Mirstat introduces two complementary mining algorithms:

- CPUs secure the network through RandomX.
- GPUs contribute additional computational security using BLAKE3.

This hybrid approach encourages participation from a wider range of miners while improving decentralization and network resilience.
